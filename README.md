# Tesselation Demonstration
A small study project that was created for learning tessellation in Unity, with volumetric snow as an example. There are 2 versions; one where the level of tessellation is calculated based on an algorithm of one's choice. And the second uses a render texture to change the level and height of the tessellated mesh on a procedurally drawn texture.
